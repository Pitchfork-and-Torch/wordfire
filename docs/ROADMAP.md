# Wordfire Ember Circle — Roadmap (after 2.0)

1. **TURN relay option** - **shipped 2.1** (`GET /api/ice` mints Cloudflare Realtime TURN; STUN-first). Needs Pages secrets `TURN_KEY_ID` + `TURN_KEY_API_TOKEN` (Calls Write). Without secrets, STUN-only fallback.
2. **Deeper decentralization** — optional public signaling (Trystero/Nostr/BitTorrent) with same game protocol.  
3. **Voice notes** — optional short WebRTC audio clips per turn (opt-in, size-capped).  
4. **Branching stories** — soft forks as alternate campfires, not competitive trees.  
5. **Richer AI friends** — local-first models; never required; clear labeling.  
6. **Public discovery (opt-in)** — themed open circles with host approval only.  
7. **Export pack** — EPUB / printable PDF of archive favorites.  
8. **Mobile install polish** — iOS share-sheet install tips, better offline SW precache.  
9. **Spectator polish** — mid-join "join next story" queue + hand raise.  
10. **Internationalization** — when i18n hold lifts fleet-wide.  

Non-goals: ads, mandatory accounts, central story mining, competitive ELO.
